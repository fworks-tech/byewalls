## Sharing

Byewalls can create temporary links for processed results.

Supported sharing methods include:

- Copy link
- Web Share API
- WhatsApp
- X

Temporary links expire automatically and can be revoked. Byewalls must not be used to access private content, bypass authentication, or circumvent access controls.

## Internet Archive

Byewalls may query historical references available through the Internet Archive and the Wayback Machine.

Archived content is identified as external content. This integration is intended for historical reference and must not be used to bypass authentication, paywalls, or other access controls.

## Privacy

Byewalls should avoid storing:

- Third-party cookies.
- Credentials.
- Private access tokens.
- Contacts.
- Private messages.
- Content beyond the required retention period.
